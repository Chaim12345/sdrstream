Station board

    
Public SDR receivers from the server probe catalog: who is alive, what each one can hear. The server sweeps; this page only reads the catalog and never contacts a station itself.

    

      Station probing is not enabled on this server.
      
The catalog endpoint answers, but no probe sweep is running. Start the server with --probe-directory to build the station catalog.
